# Tixcash Web Wallet

Browser-based wallet interface for the Tixcash network.

## Overview

Tixcash Web Wallet enables users to manage TXC assets directly from a web browser without installing software:

- Create and import wallets via mnemonic or private key
- Send and receive TXC tokens
- View real-time balance and transaction history
- Connect to staking contracts
- Sign transactions locally — keys never leave the browser
